## 2026-07-20 — Месяц 3 уроков вьетнамского (курс возобновлён)

**Проблема:** уроки кончились — в `vietnamese_lessons.json` было только 60 записей (месяцы 1-2), `current_day: 61`. Бот с ~20 мая крутил случайные повторы в режиме `review`.

**Сделано:**
- Сгенерирован месяц 3 «транспорт и навигация», дни 61-90 → 90 уроков в JSON
- `vietnamese_state.json`: `phase` вручную возвращён `review` → `course` (`current_day: 61` не трогали)
- Dry-run подтвердил: бот берёт день 61, заголовок «День 61 / 365»

**Исправлено в `pick_lesson()` (vietnamese_bot.py):**
- Было: урок брался **по индексу** (`lessons[current_day - 1]`), а не по полю `day` — любой пропуск дня в JSON сдвигал всю нумерацию, заголовок поста разъезжался с реальным номером урока. Стало: адресация через словарь `{day: lesson}`, дыры больше не влияют.
- Было: обратного перехода `review → course` не существовало — после генерации новых уроков state приходилось править руками, иначе свежие уроки растворялись в пуле повторов. Стало: если для `current_day` появился урок, бот сам выходит из повторения обратно в курс. Следующие партии месяцев подхватятся автоматически.

**Грабли:**
- День 73 с первого прогона не прошёл валидацию (пустой `tone_tip`) и был пропущен. Повторный запуск `--month 3` без `--force` догенерировал только его — остальные корректно пропущены как существующие.
- Wikibooks для месяца 3 не пригодился: `/Vietnamese/Transportation` и `/Vietnamese/Directions` → 404. Такие URL в `WIKIBOOKS_HINTS` выдуманы для большинства месяцев 3-12, реально страница нашлась только для месяца 1. Фоллбэк на чистый `claude -p` отрабатывает штатно (`source: "claude"`, как и весь месяц 2).
- В дне 61 в русский разбор затекло вьетнамское служебное слово («вместе với» вместо «вместе с») — поправлено вручную. Стоит проверять новые партии на такие протечки.

**Осталось:** месяцы 4-12 (дни 91-365) не сгенерированы. Запас — до ~18 октября 2026.

## 2026-04-26 — Расширение контента: уроки вьетнамского + гайд экспата + дайджест+

**Добавлены 3 новые рубрики для разнообразия канала:**

### 1. Утренний дайджест+ (расширение weather_bot.py)
- К погоде/AQI добавлены: курсы валют (VND/USD, VND/RUB), цена бензина A95, цена золота SJC 9999
- Источники: open.er-api.com (FX), webgia.com (бензин и золото)
- Каждая секция gracefully degraded — на ошибке выпадает, остальной пост публикуется
- Запускается в существующем cron слоте 07:00 Дананга

### 2. Уроки вьетнамского (vietnamese_bot.py)
- Ежедневный пост в 12:00 Дананга (05:00 UTC) в General
- Курс на 365 дней: 12 тематических блоков по месяцам
- Источник контента: Wikibooks Vietnamese (CC BY-SA) + дополнение через `claude -p` где Wikibooks не покрывает
- После дня 365 — режим "Повторяем" со случайным выбором (исключая последние 14 дней)
- Без аудио, только текст с кириллической транскрипцией и тон-подсказкой
- Контент готовится партиями по 30 уроков через `vietnamese_lesson_builder.py --month N`

### 3. Гайд экспата (expat_guide_bot.py)
- Еженедельный пост в воскресенье 11:00 Дананга (04:00 UTC) в General
- 39 материалов (~9 месяцев) разбитых на 8 блоков: визы, деньги, транспорт, жильё, медицина, еда/быт, связь, прочее
- Контент генерируется через `expat_guide_builder.py --id N` (claude -p), сохраняется в `expat_guide.json`
- Bot пропускает неделю если body материала ещё пустой (не падает)

### Технические решения
- Создан общий модуль `telegram_sender.py` для двух новых ботов (weather и news не трогаем)
- State-файлы (`vietnamese_state.json`, `expat_guide_state.json`) создаются при первом запуске
- Atomic write через `.tmp` + `os.replace` для всех state-файлов
- State обновляется только после успешной отправки в Telegram
- `--dry-run` флаг во всех ботах для проверки форматирования без отправки
- Все скрипты импортируют `clean_ai_output` из `news_bot.py` для фильтрации AI-meta-commentary
